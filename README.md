# cvd

Ce dépôt est une seconde copie du modèle LaTeX **autoCV** (licence MIT), utilisée comme essai
d'export PDF du CV. Le code du modèle n'est pas de moi.

Le fichier `cv.tex` contient mon CV, et une GitHub Action le compile à chaque modification.

Le contenu du modèle d'origine est conservé ci-dessous pour mémoire. Le dépôt `cv` porte la même
chose.
